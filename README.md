# E-Vocabulary UI Tests

This project contains automated tests for the [E-Vocabulary](https://e-vocabulary.vercel.app) web application.
The tests are written in **TypeScript** using the native **Playwright Test** runner and follow the **Page Object Model (POM)** design pattern.

## 1. Prerequisites

Before you begin, ensure you have **Node.js (LTS version, 18+)** and **Java 17+ (required for Allure Reports)** installed.

You also need an active account in the E-Vocabulary application.
* You can register a new account here: [https://e-vocabulary.vercel.app/](https://e-vocabulary.vercel.app/)

⚠️ After registering your account, you must update the "My known language:" setting to "ua", because the test project is configured to work with the "ua-en" language pair.

You can change this setting on the "My account" page: https://e-vocabulary.vercel.app/#/user

To open this page, either:
* navigate directly using the link above, or
* click on your profile photo to open the user menu and select "My account".

## 2. Setup and Configuration

1.  **Install Node.js dependencies:**
    Run this command in the project root to install Playwright and other required packages:
    ```bash
    npm ci
    ```

2.  **Install Playwright browsers:**
    This command will download the necessary browser binaries (Chromium, Firefox, WebKit) and system dependencies.
    ```bash
    npx playwright install --with-deps
    ```

3.  **Create an environment file:**
    Create a file named `.env` in the root directory. This file will store your credentials for running tests locally.

    Populate the `.env` file with your credentials (which are processed via `src/common/config/env.ts`):
    ```env
    USERNAME_MAIN_USER="your-username"
    PASSWORD_MAIN_USER="your-password"
    EMAIL_MAIN_USER="your-email@example.com"
    ```

## 3. Run Tests

* **Run all tests:**
    ```bash
    npx playwright test
    ```

## Reports

After the tests complete, you can view the detailed report generated by Allure (Java 17+ is required):
```bash
allure serve allure-results
